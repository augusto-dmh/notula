# Code of Conduct

Notula adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), by reference. It applies in every project space (issues, pull requests, discussions and reviews) and when you represent the project in public.

In short: be respectful and welcoming, give and accept constructive feedback gracefully, and don't harass, demean or exclude anyone.

## Reporting

To report unacceptable behavior, contact the project maintainer, Augusto Henriques, through GitHub's private channels: the same private advisory described in [`SECURITY.md`](SECURITY.md) (**Security** ▸ **Report a vulnerability** on [`augusto-dmh/notula`](https://github.com/augusto-dmh/notula)), or by contacting the maintainer [@augusto-dmh](https://github.com/augusto-dmh) on GitHub. Reports are handled confidentially. The maintainer will review each one and respond as set out in the Covenant's enforcement guidelines (correction, warning, temporary ban or permanent ban).
